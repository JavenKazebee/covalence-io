# Covalence IO

Covalence IO is open-source software for running live production. It sits in the middle of your devices: it connects them, takes input from control surfaces, and automates what happens next.

- **Plugins** for devices and services: ProPresenter, Videohub, RED cameras, OSC, HTTP, and more.
- **Surfaces** such as Stream Deck, MIDI controllers, X-keys and web buttons, each with its own pages of buttons.
- **Automation** at three levels: quick button action lists, rules ("when / if / then"), and node-based flows with JavaScript script steps.
- **Built for live shows:** crash-isolated plugins, optional redundancy and failover, multi-user editing, simulated devices, and a full timeline of everything that happened.
- **Runs on** Windows, macOS and Linux, including a Raspberry Pi. You can run it headless, through the web UI, or through the desktop app.
- **Orbital** remote nodes bring surfaces and devices on other machines into one system.
